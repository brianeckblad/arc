## When to use which:

**For list of objects:** Use `render="list"` or a specific table formatter (e.g., `render="address_objects"` for addresses)

**For single object detail:** Use `render="dict"` or a domain-specific detail formatter (e.g., `render="device_detail"`)

**For unstructured/live output:** Use `render="raw"` (logs, ping, system info)
