# Command Reference

Use `help <command>` to open detailed docs for a command.

- `commit` — Commit the candidate configuration — commit [description <text>]
- `ping host` — Ping a host — ping host <ip>
- `request system software check` — Check for available software updates
- `show address` — Show address objects
- `show address-group` — Show address groups
- `show devices` — List all managed devices
- `show high-availability all` — Show full HA status
- `show high-availability state` — Show HA state
- `show interface` — Show a specific interface — show interface <name>
- `show interface all` — Show all interfaces
- `show jobs all` — Show all jobs
- `show jobs id` — Show a specific job by ID
- `show log system` — Show system log (last 20 entries)
- `show log traffic` — Show traffic log (last 20 entries)
- `show routing route` — Show routing table
- `show routing summary` — Show routing summary
- `show security policy` — Show security policy rules
- `show service` — Show service objects
- `show system disk-space` — Show disk space usage
- `show system info` — Show system information (hostname, model, SW version, uptime...)
- `show system resources` — Show system CPU / memory resources
- `show zone` — Show security zones
- `test security-policy-match` — Test security policy match — test security-policy-match source <ip> destination <ip> application <app> protocol <n> destination-port <n>
